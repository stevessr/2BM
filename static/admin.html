Bridge administration

接入账号

QQ 使用在 NapCat 登录的真人账号；Telegram 真人账号通过 MTProto 验证码登录；Discord 仅提供官方 Bot 模式。

Telegram 真人账号登录

先添加 Telegram 真人账号；通过手机验证码与可选两步验证登录，登录会话仅保存在服务器，不会将验证码存储在浏览器。

最近消息导入（手动）

请先同步虚拟房间。仅支持 Telegram 真人账号，每次最多 50 条纯文本；会以当前时间写入 Matrix 时间线，不保留 Telegram 原始发送时间。重复导入会跳过已映射消息。

虚拟房间 · 自动发现

由 2BM 根据已登录的 QQ 好友/群聊和 Telegram 会话建立真实 Matrix 房间，并邀请账号控制者；无需手动复制房间 ID。只创建房间，不回填历史消息。

QQ 群成员同步

仅对已映射的 QQ 群房间添加虚拟成员；大群需分批处理，成员变化也会通过 OneBot 通知增量同步。

Matrix 加密兼容性警告

2BM 暂不支持 Matrix 端到端加密。若客户端将桥接房间设为加密，相关消息无法正确转发。请停止使用该房间，在 Matrix 客户端新建未加密房间并重新配置映射。

发送故障与人工核对

网络超时后，外部平台可能已经收到消息。为避免重复，2BM 会暂停这条消息的自动重试。请先在对应 QQ/Telegram 会话中检查消息：确认未发送再选“重试”，确认已发送则选“标记已送达”。操作有风险，不会自行判断平台是否收到。

手动房间映射（高级）

收到外部新会话时自动创建 Matrix 房间、邀请控制者及虚拟联系人；此处也可手动映射已有房间。
